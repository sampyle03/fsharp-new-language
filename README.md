# Numera Scientific Calculator

Once opening the project in Visual Studio:
- Right click NumeraGUI in 'Solution Explorer' and set as startup project.
- Next, 'Build' the project in 'Solution Explorer'
- Lastly, 'Run' the project.

- The GUI will load for you to interact with.
- The HelpWindow can be accessed by clicking the '?' icon to guide you with using Numera.
